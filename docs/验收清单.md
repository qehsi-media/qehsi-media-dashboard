# 新媒体数据看板全流程验收清单

## 启动命令

```bash
cd /Users/qehsi/Documents/Trae-CN/default
source .venv/bin/activate
streamlit run app.py
```

浏览器访问 `http://localhost:8501`。如需重新初始化数据库结构及 7 个账号，可执行：

```bash
.venv/bin/python -m db.database
```

所有数据必须来自用户在平台后台导出并手动上传的 CSV/XLSX 文件；验收过程不使用自动登录、Cookie 复用、浏览器自动化、爬虫或平台接口抓取。

## 1. 上传抖音文件一次

- [ ] 打开“数据上传”，平台选择“抖音”。
- [ ] 选择与文件一致的抖音账号，上传后台导出的 CSV/XLSX。
- [ ] 检查前 10 行预览和全部中文列名。
- [ ] 核对映射：作品标题→content_title、发布时间→publish_time、播放量→views、点赞数→likes、评论数→comments、分享数→shares、收藏数→favorites、作品链接→link。
- [ ] 点击“保存映射并入库”，确认显示上传行数、成功入库、失败和重复跳过统计。
- [ ] 再次上传相同文件，确认映射自动套用，重复内容被跳过。

## 2. 上传视频号文件一次

- [ ] 平台切换为“视频号”，选择对应视频号账号，上传后台导出的 CSV/XLSX。
- [ ] 核对映射：视频标题→content_title、发布时间→publish_time、播放量/观看量→views、点赞数→likes、评论数→comments、分享/转发→shares、收藏数→favorites、视频链接→link。
- [ ] 点击“保存映射并入库”，确认成功入库统计。
- [ ] 切换回抖音再切回视频号，确认视频号使用自己的映射，不覆盖抖音映射。

## 3. 上传公众号文件一次

- [ ] 平台切换为“公众号”，选择“青实高国际”，上传后台导出的 CSV/XLSX。
- [ ] 核对映射：文章标题→content_title、发表/发布时间→publish_time、阅读数/阅读量→views、点赞数→likes、留言/评论数→comments、转发/分享→shares、在看/收藏→favorites、文章链接→link。
- [ ] 点击“保存映射并入库”，确认成功入库统计。
- [ ] 确认公众号映射与抖音、视频号映射分别保存。

## 4. 查看本月核心数据

- [ ] 打开“数据看板”，选择上传内容对应月份。
- [ ] 核对总播放/阅读量、点赞、评论、分享、收藏、内容总数和覆盖账号数。
- [ ] 检查 7 个账号的表现表和互动量排名图。
- [ ] 检查抖音、视频号、公众号平台汇总及曝光占比。
- [ ] 切换到无数据月份，确认显示“本月暂无数据，请先上传”。

## 5. 查看各平台爆款

- [ ] 打开“爆款与矩阵”，选择对应月份。
- [ ] 分别查看抖音爆款、视频号爆款、公众号爆款。
- [ ] 调整爆款倍数阈值，确认爆款结果和 IP 矩阵中的爆款数同步变化。
- [ ] 点击爆款链接列，确认链接可打开（源文件提供有效链接时）。

## 6. 查看 IP 矩阵

- [ ] 确认矩阵显示全部 7 个账号。
- [ ] 核对内容数、总曝光、总互动、平均互动、爆款数和最近发布时间。
- [ ] 确认数值列有颜色深浅标记。

## 7. 查看多平台联动

- [ ] 在“多平台联动分析”中选择统计月份。
- [ ] 切换 topic / content_type 聚合维度。
- [ ] 核对同一主题在不同平台的发布数量、总互动和平均互动。
- [ ] 确认空 topic 归为“未标注主题”，空 content_type 归为“未标注类型”。

## 8. 生成并下载月度报告

- [ ] 打开“月度报告”，选择有数据的月份，点击“生成本月报告”。
- [ ] 检查核心数据、平台表现、账号表现、爆款摘要、联动摘要、服务价值小结和后期建议七个章节。
- [ ] 在“复制 Markdown”中复制报告原文。
- [ ] 点击“下载 Markdown 报告（.md）”，确认下载文件可正常打开且中文无乱码。
- [ ] 点击“重新生成”，确认生成最新报告并再次保存。
- [ ] 切换到无数据月份，确认显示“本月暂无数据，无法生成报告”。

## 9. 数据库核查

```bash
sqlite3 db/media_dashboard.db "SELECT platform, COUNT(*) FROM contents GROUP BY platform;"
sqlite3 db/media_dashboard.db "SELECT platform, COUNT(*) FROM field_mappings GROUP BY platform;"
sqlite3 db/media_dashboard.db "SELECT id, report_month, created_at FROM analysis_reports ORDER BY id DESC;"
```

- [ ] contents 中包含 douyin、wechat_video、wechat_mp 三类已上传数据。
- [ ] field_mappings 按平台分别保存。
- [ ] analysis_reports 中可查到已生成报告。
